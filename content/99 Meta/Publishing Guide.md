# Publishing Guide

[[00 Home/Start Here|Home]]

This vault is plain Obsidian-compatible Markdown designed for player publication. It contains no links into private vaults and no ChatGPT-, system-, workflow-, or canon-audit tags.

## Publication boundary

- Publish this vault independently from the GM vault.
- Do not copy unrevealed source notes into the public content tree.
- Review additions against [[00 Home/Reader Guide|Reader Guide]].
- Treat all files in `90 Assets` as public player material.

Ordinary wikilinks and minimal frontmatter make the files suitable for Obsidian and Quartz-style static publishing.
