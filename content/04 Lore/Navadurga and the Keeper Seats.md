# Navadurga and the Keeper Seats

[[04 Lore/Lore Index|Lore Index]] · [[03 Factions/Nine Keepers|Nine Keepers]]

The Navadurga provide the nine sacred aspects reflected in the names and offices of the Nine Keepers.

| Community | Navadurga aspect |
| --- | --- |
| Highborne | Mahagauri |
| Loreborne | Siddhidhatri |
| Orderborne | Brahmacharini |
| Ridgeborne | Shailaputri |
| Seaborne | Chandraghanta |
| Skyborne | Kushmanda |
| Slyborne | Kalaratri |
| Wanderborne | Skandamata |
| Wildborne | Katyayani |

This mapping is authoritative. A larger mythic cycle has not yet been released as public canon.
